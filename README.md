# @sofainerobot Landing Page

Modern, fully responsive dark-mode landing page for the @sofainerobot Telegram bot.

## Stack

- [Next.js 14](https://nextjs.org/) (App Router)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) (icons)
- TypeScript

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Sections

1. **Navbar** — Logo + "Start Bot" CTA
2. **Hero** — Headline, description, and "Launch @sofainerobot" button linking to t.me/sofainerobot
3. **Features** — 4 feature cards with icons (Fast Responses, 24/7 Availability, Secure & Private, AI-Powered)
4. **How It Works** — 3-step guide
5. **Footer** — Copyright + bot link

## Design

- Dark mode by default (deep grays + neon cyan/emerald/purple accents)
- 100% mobile-responsive
- Smooth hover animations on buttons and cards
